# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

### Anisong_Finder
- https://gemini.google.com/share/61fc35983c01
- 애니메이션 제목을 입력하면 해당 애니메이션의 ost 목록을 불러오는 앱입니다.
- 애니메이션 대표 포스터와 함께 간단한 줄거리도 확인할 수 있습니다.
- ost 옆 유튜브 아이콘을 클릭하면 유튜브 검색 링크로 이동하여 바로 ost를 확인할 수 있습니다.

### 알까기
- https://gemini.google.com/share/008ac15372c9
- 간단한 알까기 게임입니다.
- 흑과 백으로 팀이 나누어지며 바둑알의 크기가 랜덤으로 정해집니다.
- 한 턴이 끝날 때마다 판의 모양이 랜덤하게 변경되어 긴장감을 더해줍니다.
- 바둑알을 드래그하여 힘을 조절할 수 있고 바둑알의 예상 경로를 보여줍니다.

### 자바 개념 다지기
- https://gemini.google.com/share/912b010b7b5f
- 난이도에 맞게 자바의 개념을 학습할 수 있는 퀴즈입니다.
- 난이도, 문항 수, 제한 시간을 설정하면 AI가 퀴즈를 생성합니다.
- 퀴즈가 끝나면 AI가 채점을 진행한 후 점수를 알려줍니다.
- 이후 맞은 문제, 틀린 문제, 전체 문제에 대한 해답을 보여줍니다.
